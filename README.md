## 🔐 Aktivasi License

License Gomopage berbasis **Hardware ID (HWID)** — terikat ke 1 device.

### Langkah Aktivasi

```
1. Buka aplikasi Gomopage
2. Catat / copy HWID yang tampil di halaman aktivasi
3. Kirim HWID ke admin untuk mendapatkan license key
4. Paste license key di kolom yang tersedia
5. Klik Aktifkan → dashboard langsung terbuka
```

### Format License Key

```
GOMO-LIFETIME-ABCD1234-EFGH5678-IJKL9012-MNOP3456
GOMO-1750000000000-ABCD1234-EFGH5678-IJKL9012-MNOP3456
```

### Tipe License

| Tipe | Keterangan |
|---|---|
| `LIFETIME` | Tidak ada expired |
| `30 hari` | Expired sesuai durasi pembelian |
| `custom` | Sesuai paket yang dibeli |

> ⚠️ License hanya berlaku untuk **1 device/PC**. Jangan share ke orang lain.

## 🎨 Format Template HTML

Template adalah file `.html` biasa. Gunakan placeholder `{{variable}}` untuk konten dinamis.

### Variabel yang Tersedia

```html
<!-- Data Domain -->
{{title}}           <!-- meta title halaman -->
{{description}}     <!-- meta description SEO -->
{{site_name}}       <!-- nama brand -->
{{keyword}}         <!-- keyword utama -->
{{linkdaftar}}      <!-- URL tombol daftar/CTA -->
{{canonical}}       <!-- URL canonical domain -->
{{year}}            <!-- tahun sekarang (otomatis) -->

<!-- Asset Gambar -->
{{logo}}            <!-- file logo -->
{{favicon}}         <!-- file favicon -->
{{hero}}            <!-- file banner/hero utama -->
{{bannerutama}}     <!-- alias {{hero}} untuk template lama -->

<!-- Konten AI -->
{{h1}}              <!-- heading utama -->
{{intro}}           <!-- paragraf intro -->
{{about_title}}     <!-- judul about -->
{{about_text}}      <!-- teks about -->
{{benefit_1_title}} <!-- judul benefit 1 -->
{{benefit_1_text}}  <!-- teks benefit 1 -->
{{benefit_2_title}} <!-- judul benefit 2 -->
{{benefit_2_text}}  <!-- teks benefit 2 -->
{{benefit_3_title}} <!-- judul benefit 3 -->
{{benefit_3_text}}  <!-- teks benefit 3 -->
{{faq_1_q}}         <!-- FAQ pertanyaan 1 -->
{{faq_1_a}}         <!-- FAQ jawaban 1 -->
{{faq_2_q}}         <!-- FAQ pertanyaan 2 -->
{{faq_2_a}}         <!-- FAQ jawaban 2 -->
{{faq_3_q}}         <!-- FAQ pertanyaan 3 -->
{{faq_3_a}}         <!-- FAQ jawaban 3 -->
{{cta_title}}       <!-- judul CTA -->
{{cta_text}}        <!-- teks CTA -->
{{cta_button}}      <!-- teks tombol CTA -->
```

### Contoh Template Minimal

```html
<!DOCTYPE html>
<html lang="id">
<head>
  <meta charset="UTF-8">
  <title>{{title}}</title>
  <meta name="description" content="{{description}}">
  <link rel="canonical" href="{{canonical}}">
  <link rel="icon" href="{{favicon}}">
</head>
<body>
  <header>
    <img src="{{logo}}" alt="{{site_name}}">
  </header>

  <main>
    <img src="{{hero}}" alt="hero">
    <h1>{{h1}}</h1>
    <p>{{intro}}</p>
    <a href="{{linkdaftar}}">{{cta_button}}</a>
  </main>

  <footer>© {{year}} {{site_name}}</footer>
</body>
</html>
```

## 🤖 Konfigurasi OpenAI

Buka **Settings → Konfigurasi OpenAI**.

### ⚠️ Wajib: Test Koneksi Setelah Isi API Key

Setiap kali kamu mengisi atau mengganti API Key, **wajib klik tombol `Test Koneksi AI`** sebelum mulai generate.

Tombol ini akan langsung memanggil OpenAI dan menampilkan notifikasi hasilnya di pojok kanan bawah layar:

| Notifikasi yang Muncul | Artinya | Tindakan |
|---|---|---|
| 🟢 `AI Terkoneksi ✓ — Response: OK` | API Key valid, siap digunakan | Langsung bisa generate |
| 🔴 `API Key belum diisi` | Kolom API Key masih kosong | Isi API Key lalu klik Simpan dulu |
| 🔴 `Koneksi AI Gagal — ...401...` | API Key salah atau sudah dinonaktifkan | Cek & ganti API Key |
| 🔴 `Koneksi AI Gagal — ...429...` | Kuota OpenAI habis atau terlalu banyak request | Tunggu beberapa menit atau upgrade plan |
| 🔴 `Koneksi AI Gagal — ...400...` | Format request tidak dikenal, biasanya karena model | Ganti model di Settings (coba `gpt-4o`) |
| 🔴 `Koneksi AI Gagal — ...403...` | Akun tidak punya akses ke model yang dipilih | Ganti ke model yang tersedia di akun kamu |
| 🔴 `Koneksi AI Gagal — ...500...` | Server OpenAI sedang gangguan | Tunggu beberapa menit lalu coba lagi |

> ⚠️ **Jika test gagal, jangan lanjut generate.** AI tidak akan berjalan dan semua domain akan pakai konten fallback SVG lokal tanpa peringatan error yang jelas di setiap domain.

### Toggle Fitur

| Toggle | Rekomendasi | Keterangan |
|---|---|---|
| Aktifkan OpenAI | ✅ ON | Master switch AI |
| AI Text Generator | ✅ ON | Isi konten otomatis |
| AI Image Generator | ⚠️ Opsional | Generate gambar, biaya lebih mahal |
| AI Logo | ❌ OFF | Matikan dulu, pakai upload manual |
| AI Favicon | ❌ OFF | Matikan dulu, pakai upload manual |

### Model yang Tersedia

| Kebutuhan | Model |
|---|---|
| Text (hemat) | `gpt-4o-mini` |
| Text (terbaik) | `gpt-4o` / `gpt-5.5` |
| Image | `gpt-image-2` / `dall-e-3` |

## ⛔ Arti Kode Error API

Kode error ini muncul di **Live Log** saat generate, atau di notifikasi saat **Test Koneksi AI**.

### Error Kode HTTP

| Kode | Nama | Penyebab | Solusi |
|---|---|---|---|
| `400` | Bad Request | Model tidak mengenali format request, biasanya karena nama model salah atau parameter tidak didukung | Ganti model ke `gpt-4o` atau `gpt-4o-mini` di Settings |
| `401` | Unauthorized | API Key salah, expired, atau sudah dihapus dari akun OpenAI | Buka [platform.openai.com](https://platform.openai.com/api-keys), buat API Key baru, paste ke Settings |
| `403` | Forbidden | Akun tidak punya akses ke model yang dipilih (misal: model premium tapi akun free) | Pilih model yang sesuai tier akun, atau upgrade akun OpenAI |
| `429` | Too Many Requests | Kuota token habis, atau terlalu banyak request dalam waktu singkat (rate limit) | Tunggu 1–2 menit, cek usage di [platform.openai.com/usage](https://platform.openai.com/usage), atau upgrade plan |
| `500` | Internal Server Error | Server OpenAI sedang gangguan atau down | Tunggu beberapa menit, cek status di [status.openai.com](https://status.openai.com) |
| `503` | Service Unavailable | OpenAI overload, terlalu banyak user bersamaan | Coba lagi beberapa menit kemudian |

### Error Non-HTTP

| Pesan Error | Penyebab | Solusi |
|---|---|---|
| `API Key belum diisi atau OpenAI tidak terinstall` | Kolom API Key kosong, atau toggle Aktifkan OpenAI masih OFF | Isi API Key, centang Aktifkan OpenAI, klik Simpan |
| `Cannot read properties of null` | OpenAI client gagal dibuat karena key kosong | Isi API Key lalu klik Simpan AI Config sebelum test |
| `ECONNREFUSED` / `ENOTFOUND` | Tidak ada koneksi internet atau firewall memblokir | Cek koneksi internet, matikan VPN sementara, atau whitelist domain `api.openai.com` |
| `insufficient_quota` | Kredit OpenAI habis | Top up kredit di [platform.openai.com/settings/billing](https://platform.openai.com/settings/billing) |
| `model_not_found` | Nama model yang diketik tidak ada | Pilih model dari dropdown di Settings, jangan ketik manual |

### Cara Baca Log Error saat Generate

Di halaman **Generate → Live Log**, error AI ditampilkan seperti ini:

```
[AI TEXT ERROR] 401 Unauthorized - No API key provided
[AI IMAGE ERROR] hero: 429 Too Many Requests
[ERROR] namadomain.com — template tidak ditemukan
```

- Baris `[AI TEXT ERROR]` → masalah di pembuatan konten teks
- Baris `[AI IMAGE ERROR]` → masalah di pembuatan gambar (hero/logo/favicon)
- Baris `[ERROR]` → domain gagal diproses secara keseluruhan
- Domain yang error tetap menghasilkan file output, tapi menggunakan **konten & gambar fallback lokal**

## 🛠️ Troubleshooting

<details>
<summary><b>❌ Halaman aktivasi tidak muncul</b></summary>

Tutup aplikasi, lalu buka ulang sebagai **Run as Administrator**.

</details>

<details>
<summary><b>❌ License key tidak diterima</b></summary>

- Pastikan HWID yang dikirim ke admin sudah benar
- License key hanya berlaku untuk 1 device
- Cek apakah license sudah expired

</details>

<details>
<summary><b>❌ Dashboard tidak terbuka setelah aktivasi</b></summary>

Tutup dan buka ulang aplikasi. Pastikan tidak ada antivirus yang memblokir proses Node.js di dalam app.

</details>

<details>
<summary><b>❌ Logo / hero tidak muncul di preview</b></summary>

- Upload ulang gambar saat edit domain
- Generate ulang setelah upload gambar baru

</details>

<details>
<summary><b>❌ AI text tidak berjalan / konten generik</b></summary>

- Klik **Test Koneksi AI** di Settings untuk melihat error detail
- Pastikan toggle **Aktifkan OpenAI** dan **AI Text Generator** sudah ON
- Lihat baris `[AI TEXT ERROR]` di Live Log untuk kode error spesifik
- Cocokkan kode error dengan tabel di section [Arti Kode Error API](#-arti-kode-error-api)

</details>

<details>
<summary><b>❌ Generate error semua domain</b></summary>

- Pastikan template sudah diupload di menu Templates
- Nama template di kolom domain harus **sama persis** dengan nama file di folder Templates (termasuk huruf besar/kecil)

</details>

<details>
<summary><b>❌ License expired</b></summary>

Aplikasi otomatis kembali ke halaman aktivasi. Hubungi admin untuk perpanjang license dengan HWID yang sama.

</details>
